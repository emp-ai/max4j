# Участие в разработке

Создайте fork и отправьте pull request в `main`. Опишите проблему, изменение и способ проверки.
Существенные изменения API сначала обсудите в issue. Можно писать на русском или английском.

Для сборки нужна Java 21:

```bash
./mvnw --batch-mode verify
python3 -m unittest discover -s .github/scripts/tests -v
```

В Windows используйте `mvnw.cmd` и доступную команду Python 3. Токен бота для тестов не нужен.
Код клиента и моделей генерируется из `core/src/main/openapi/max-api.yaml`: меняйте схему
или настройки генератора, а не файлы в `target/`. При обновлении схемы укажите её источник и версию.

Для изменения поведения добавляйте тесты, для изменения публичного API обновляйте примеры.
CI внешних PR запускается после подтверждения сопровождающего. Секреты и данные пользователей
в issue и PR не добавляйте; об уязвимостях сообщайте по [правилам безопасности](SECURITY.md).

Изменения принимаются под Apache-2.0. Отправляя PR, вы подтверждаете право передать этот код
под данной лицензией. Сохраняйте сведения о сторонних компонентах и их лицензиях.
