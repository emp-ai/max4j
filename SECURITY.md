# Безопасность

Об уязвимостях сообщайте через [закрытую форму GitHub](https://github.com/emp-ai/max4j/security/advisories/new).
Укажите версию, возможные последствия и пример воспроизведения на вымышленных данных.
Ключи и переписку пользователей не публикуйте в открытых issue и PR.

Токен бота и секрет webhook храните в переменных окружения или хранилище секретов приложения.
Для рабочего webhook используйте HTTPS и проверку секрета. При утечке ключ нужно заменить.
